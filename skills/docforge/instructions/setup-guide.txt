# Setup Guide Instruction Template

## Purpose
Step-by-step environment setup for developers getting started.

## Target Audience
Engineers (new and existing)

## Required Sections
1. Prerequisites - what must be installed first (OS, tools, versions)
2. Installation steps - exact commands to set up environment
3. Verification - how to verify setup worked
4. Troubleshooting - common setup problems and solutions

## Data Requirements
- Knowledge graph (optional)
- Direct inspection (run the setup steps yourself first)

## Depth Level
L1 - Clear, step-by-step, no deep explanation

## Template Structure
- Lead with: "This guide sets up [system] for [what purpose]"
- List prerequisites with version constraints (from manifests/package files)
- Numbered installation steps with exact shell commands
- For each step: what it does, what to expect if successful
- Verification section: how to test each part works
- Troubleshooting: common failure modes and fixes

## Provenance Requirements
- Reference configuration files (pyproject.toml, package.json, etc.) for versions
- Tag commands with which docs/setup section they come from
- Record scripts or manual steps tested and working

## Common Pitfalls
- Don't assume shell knowledge - show exact commands, not pseudo-code
- Don't skip steps because "obvious" - new developers are audience
- Don't use relative paths - spell out repo root or use $HOME or $(pwd)
- Don't forget to verify each step - have user confirm setup worked
- Don't store secrets or tokens in this doc (use environment variable examples)

## Notes
- This is a primary onboarding document - invest in clarity
- Test every command yourself before writing it
- Include expected output for key verification steps
- Link to troubleshooting guides if your system has known gotchas
