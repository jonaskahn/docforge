# Writing-craft instructions

**Preferred illustration:** All craft guides defer form selection, syntax,
accessibility, and depth budgets to
[`../references/illustration.md`](../references/illustration.md).

Instruction files describe how to shape a particular document. They do not own
selection, workflow, evidence policy, content requirements, depth, provenance,
audit, or quality gates.

For each document:

1. Read its machine definition in `.metadata/catalog.json`.
2. Read its contract in `references/document-catalog.md`.
3. Use the optional `instruction_file` only for craft such as narrative order,
   diagram choice, table design, and reader vocabulary.

When adding a craft guide, reference it from the catalog and keep the content
contract out of this directory.
