# Writing `docs/engineering.md`

The compact engineering file. Write one `##` section per member, in this
reading order, grounding each section from the evidence its member contract
requires:

1. `## At a glance` — folder-index orientation (how this repository is built
   and tested).
2. `## Setup` — `setup-guide` (getting a working checkout).
3. `## Testing` — `testing-guide` (how to run and extend the test suite).

Ground each section from the repository evidence cited in provenance — one
provenance `sections[]` entry per `##` heading. Do not add sections beyond the
composed contract, and do not route readers into source files.
