# `quickstart`

**Reader question** — "Can I get one useful result from this in under a minute of reading?"

| Mode | Depth | Shape |
|---|---|---|
| How-to | deep-dive | executable-procedure |

The smallest useful slice of `setup_guide`'s how-to discipline — one verified path to one first result, not a second copy of full setup.

## Must present

| # | Element | At | Done wrong |
|---|---|---|---|
| 1 | Prerequisites, stated in one line | L0 | a prerequisite discovered mid-procedure |
| 2 | One command block | L1 | a plausible command presented as verified when verification could not run |
| 3 | The expected output | L2 | a command with no stated expected output |
| 4 | One or two "what next" links | L3 | ending on a command with no stated outcome or next step |

## Keep out

| Not here | Lives in |
|---|---|
| Full setup, configuration, or troubleshooting content | `setup_guide` |
| An unverified command presented as verified | nowhere — state the blocker instead |

## Owns / links

| Owns | Links to | Because |
|---|---|---|
| The shortest verified path to one first useful result | `setup_guide` | full install, configuration, and troubleshooting are owned there |
| What this product does for the reader | `product_overview` | the "what next" orientation is owned there |
