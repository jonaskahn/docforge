# Accessibility writing craft

**Preferred illustration:** Follow
[`../../../references/illustration.md`](../../../references/illustration.md); a table
for the conformance checklist, prose for verification method and gaps.

State the WCAG conformance level actually targeted (A, AA, or AAA) and per
which success criteria area (perceivable, operable, understandable,
robust) — a bare "we care about accessibility" claim with no level stated
is not a claim a reader can verify against. State the verification method
per area: automated scan, manual audit, or assistive-technology testing —
name which, since they catch different defects.

Close with known gaps stated as plainly as the covered areas — an
accessibility document with no gaps section on a nontrivial UI reads as
either complete or unaudited; say which. Never claim a compliance
certification the repository hasn't evidenced.
