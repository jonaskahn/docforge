- `portfolio-glossary.md` — Cross-repository decision evidence or shared terminology with member links → [portfolio-glossary.md](portfolio-glossary.md)
- `portfolio-operations.md` — Cross-repo controls, gaps, shared dependencies, operational coupling → [portfolio-operations.md](portfolio-operations.md)
- `repo-inventory.md` — Discovered repositories, role, owner token, documentation state, evidence → [repo-inventory.md](repo-inventory.md)
- `security-posture.md` — Cross-repo controls, gaps, shared dependencies, operational coupling → [security-posture.md](security-posture.md)
- `system-context.md` — Repository/system boundaries, shared services, cross-repo flows, directed dependency edges between members with coupling type and resolution confidence → [system-context.md](system-context.md)
